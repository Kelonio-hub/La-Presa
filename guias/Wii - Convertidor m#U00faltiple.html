Conversión Múltiple DOL

⚠️ Importante: Asegúrate de mantener la estructura original de las carpetas internas de la herramienta para evitar errores de dependencias durante los procesos de conversión.

Requisitos

  • Un ordenador con sistema operativo Windows.
  • El archivo ejecutable (.dol, .elf o .bin) de Wii que deseas convertir.
  • Paquete de herramientas Conversor Múltiple v0.3:
    Hacerse miembro Descargar Archivos

PASO 1: Preparación de Archivos

  1. Descarga el paquete "Archivos v0.3" desde el enlace superior y extrae su contenido dentro de una carpeta accesible en tu ordenador.
  2. Copia el archivo original que deseas convertir (.dol, .elf, o .bin) y pégalo directamente en la raíz de la carpeta donde se extrajeron las herramientas.

PASO 2: Selección del Tipo de Conversión

  1. Conversión de .DOL a .ELF: Ejecuta el ejecutable o script correspondiente a dol2elf. Selecciona tu archivo .dol y el proceso generará automáticamente la versión ejecutable .elf correspondiente.
  2. Conversión de .ELF a .DOL: Ejecuta la herramienta elf2dol. Arrastra tu archivo ejecutable .elf al programa o interactúa mediante la interfaz de comandos para compilar el formato nativo .dol de Wii.
  3. Conversión de .DOL a .BIN: Abre la utilidad de conversión a binario plano. El software extraerá las secciones de código y datos del ejecutable original .dol para compilar un archivo crudo .bin utilizable.
  4. Conversión de .BIN a .DOL: Emplea la herramienta de reconstrucción binaria. Ingresa el archivo .bin de origen con las direcciones de memoria de inicio correctas para reconstruir la estructura ejecutable nativa .dol.
✅ ¡Enhorabuena! El proceso se ha completado correctamente. Tu nuevo archivo convertido estará disponible inmediatamente en el directorio de salida.

Si experimentas problemas de ejecución con algún archivo de salida, comprueba que las cabeceras binarias originales no estuvieran corruptas.
